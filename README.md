## ภาพรวมโครงสร้างระบบ (Topology Overview)
ระบบเชื่อมต่อเครือข่ายศูนย์กลาง HQ Data Center กับโรงงานทั้ง 4 แห่งผ่าน Fiber Optic และ Wireless Bridge :
1. Smart EV Electronics Factory
2. Smart Packaging Factory
3. Automotive Assembly Plant
4. Luminatech Smart Lighting Factory

## อุปกรณ์หลักที่ใช้งาน (Core Equipment)
* Core Router / Branch Router : Cisco 2911 Integrated Services Router
* Switch : Cisco Catalyst 2960-24TT Layer 2 Switch
* Backbone Cable : Single-Mode Fiber Optic (Armored Cable)
* Local LAN : Cat6 UTP (Office) / Cat6A STP (Production Factory)
